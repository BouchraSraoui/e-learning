# Progression, reprise et fin d'un cours
URL: /my-learning

Votre progression est enregistrée automatiquement pendant que vous apprenez : leçons terminées, position de lecture dans les vidéos et temps passé. Si vous quittez un cours, vous reprenez exactement où vous vous étiez arrêté, depuis « Mes formations » ou le bouton « Reprendre » du tableau de bord.

La barre de progression d'un cours reflète les leçons terminées et les quiz réussis. Un cours est terminé lorsque toutes ses leçons sont marquées comme terminées et que tous ses quiz publiés sont réussis. Marquez une leçon comme terminée avec le bouton prévu dans le lecteur.

Les leçons se consultent directement dans la plateforme : vidéos et audio avec reprise de lecture, documents PDF et présentations dans la visionneuse intégrée, leçons texte enrichies. Les fichiers non lisibles dans le navigateur (par exemple PowerPoint) proposent un bouton de téléchargement.
