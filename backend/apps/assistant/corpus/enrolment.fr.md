# S'inscrire à un cours et retrouver ses formations
URL: /catalog

Ouvrez le Catalogue pour parcourir tous les cours publiés. Vous pouvez rechercher par mots-clés et filtrer par catégorie, niveau, format (vidéo, audio, PDF, présentation, texte) ou durée. Cliquez sur un cours pour voir sa fiche : description, objectifs, chapitres et leçons, ressources téléchargeables et prérequis.

Pour vous inscrire, cliquez sur « S'inscrire » sur la fiche du cours. Le cours apparaît immédiatement dans « Mes formations », où vos inscriptions sont classées par statut : tous, en cours, terminés.

Votre manager peut aussi vous assigner un cours : il apparaît alors automatiquement dans « Mes formations ». Les cours marqués « obligatoire » doivent être terminés par tous les employés concernés ; ceux qui vous restent sont mis en avant sur votre tableau de bord.
