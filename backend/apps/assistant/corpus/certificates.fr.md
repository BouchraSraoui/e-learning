# Certificats : obtention, téléchargement et vérification
URL: /certificates

Un certificat est délivré automatiquement lorsque vous terminez un cours qui en délivre : toutes les leçons terminées et tous les quiz réussis. Vous recevez une notification, et votre manager est informé.

Retrouvez vos certificats dans la page « Certificats ». Chaque certificat peut être téléchargé en PDF. Il porte un code de vérification unique et infalsifiable : n'importe qui peut confirmer son authenticité en saisissant ce code sur la page publique de vérification (/verify), sans compte.

Vos certificats apparaissent aussi dans votre profil (relevé de formation) et les plus récents sur votre tableau de bord. Remarque : certains cours, à la discrétion de leur auteur, ne délivrent pas de certificat ; leur fiche l'indique.
